# 拾用 · 单文件开发者工具集

JSON 格式化、压缩、转义与去转义、Unix 时间戳转换、Base64 编解码、文本对比、Unicode 编解码。中文响应式界面，所有转换均在浏览器中进行，依赖已内联，无外部资源请求或内容持久化。支持 PDF 分割与 ZIP 下载。

## 开发与交付

需要 **Bun 1.3.13 或更高版本**。首次安装：

```sh
bun install --frozen-lockfile
bun run dev
```

访问 `http://127.0.0.1:3000`，修改源码后刷新浏览器即可看到变化。可通过 `PORT` 环境变量指定端口。开发服务器只监听本机地址。

```sh
bun run typecheck    # TypeScript 严格检查
bun test             # 转换逻辑与单文件构建测试
bun run format:check # 源码格式检查
bun run build        # 生成 dist/index.html
```

**交付时只需复制 `dist/index.html`**，双击即可离线使用，也可放在任意静态服务器上。HTML 内含所有脚本、CSS 和 SVG，不需要 Bun、node_modules 或服务器。兼容支持 BigInt、TextEncoder、TextDecoder 的现代 Chrome、Edge、Firefox 和 Safari。

`bun run format` 统一源码排版。`bun.lock` 固定开发依赖；生产页面的第三方依赖已内联，无外部资源请求。

添加工具时，在 `src/tools/<名称>/` 编写独立的 `convert.ts` 和 `view.ts`，在 HTML 添加带唯一 ID 的面板与导航链接，在 `main.ts` 注册挂载函数，并添加转换测试。转换层不引用 DOM；通用界面交互优先复用 `ui` 模块。

CSS 通过 `base`、`layout`、`components`、`responsive` 四个层级组织，颜色、圆角与字体统一使用变量。新增图标应使用内联 SVG，字体使用系统字体。

## 行为约定

### JSON

- 格式化与压缩严格校验 JSON，不接受注释、尾随逗号或空输入。支持所有合法顶层 JSON 值。
- 格式化与压缩时，原生解析器仅用于校验；输出直接调整原始 token 之间的空白，不重新序列化解析值。因此保留大整数、指数、负零、重复键、键顺序及字符串转义写法。
- 格式化默认缩进 2 个空格，可选 4 个空格或 Tab。压缩仅去掉字符串外空白。
- 转义将全文按 JSON 字符串规则编码，不带外层双引号，例如 `{"a":1}` → `{\"a\":1}`。支持普通文本，保留中文和 emoji；不解析内部 JSON，往返转换保留数值、重复键、排版及原有转义写法。
- 去转义兼容 `{\"a\":1}` 和 `"{\"a\":1}"`，每次只还原一层，不自动格式化，也不要求结果为合法 JSON。完整字符串外围的空白不属于字符串内容；不带外层引号时保留原有空格。
- 转义与去转义拒绝空编辑框；纯空白作为文本处理，去转义时实际换行和制表符仍需写成 `\n`、`\t` 等转义形式。完整字符串 `""` 可还原为空文本。无效转义或未转义的内部双引号会报错并保留原文。

### 时间戳

- 明确选择输入单位，默认毫秒。秒支持最多 9 位小数，毫秒最多 6 位小数，纳秒只接受整数；不接受科学计数法。
- 内部统一使用 `bigint` 纳秒。单位转换不经过浮点数；负时间戳的日历拆分使用向下取整，避免纪元前的精度错误。
- 日期支持 `YYYY-MM-DD HH:mm:ss[.小数]` 或 `T` 分隔符，可附加 `Z`、`±HH:mm`；小数为 1～9 位。也支持 ISO 扩展年份，以及历史时区使用的 `±HH:mm:ss` 偏移。
- 未指定偏移的日期使用所选的本地时区或 UTC；显式偏移优先。日期结果固定显示 9 位小数，并附偏移，可直接重新输入。
- 使用浏览器的时区数据库。本地夏令时跳过的时间被拒绝，重复时间使用较早时刻；结果显示实际偏移。非法日期、闰秒、24:00:00 及超出 Date 范围的时间会报错。
- “填入当前时间”使用 `Date.now()`，精度为毫秒，额外小数位为零。

### Base64

- 文本使用 UTF-8，支持中文和 Emoji，保留 BOM；不完整的 Unicode 代理字符会报错。
- 标准编码使用 `+/` 和 `=` 填充。Base64URL 使用 `-_`，编码省略填充。
- 解码允许 ASCII 空白及合法省略填充，但检查字母表、长度、填充数量与未使用的末尾位。不匹配所选类型、无效 UTF-8 或二进制内容会报错。
- 空文本是合法输入。大文本按字节分块编码，避免一次性展开整个数组。

### 文本对比

- 从“文本对比”导航或 `#diff` 打开。输入原文和新文本，停止输入 300ms 后自动比较；中文输入法组合输入期间暂停计算。
- 左右结果对齐显示双方行号，用 `+`、`−`、`~` 和颜色标记新增、删除及修改。修改行内的差异进一步高亮；连续增删块按顺序配对为修改行，剩余行单独标记。
- 默认精确比较行内空白及大小写。CRLF、CR 统一按 LF 处理，保留空行及末尾换行差异；末尾换行以独立行标记。双侧为空时提示输入，单侧为空时全部标记为新增或删除。
- “忽略空白”去除行内及首尾空白用于比较，保留换行和空行；“忽略大小写”使用 Unicode 小写转换。选项同时影响行级和行内比较，结果始终展示未经改写的原文。
- 行内优先通过 `Intl.Segmenter` 划分可见字符，正确处理 Emoji 序列和组合字符；不支持该 API 时按 Unicode 码点拆分，保留完整代理对。
- 每侧最多 200,000 个 UTF-16 代码单元（字符计数口径）、5,000 行，包含末尾换行对应的空行。Myers 搜索和序列比较共用 2,000,000 步预算；行级超限时停止并保留输入，行内预算耗尽时退化为整行高亮并说明。
- 提供交换两侧、清空和示例。输入或选项变化时清除旧结果，重新等待计算；工具切换保留文本和选项，刷新清空。当前不包含文件导入、差异导出和文本合并。
- 结果采用文本节点渲染，不解析用户 HTML。桌面左右输入，手机上下输入；双栏结果在容器内横向滚动，五项工具导航也可横向滚动。

### Unicode

- 从导航末尾第 05 项“Unicode 编解码”或 `#unicode` 打开。提供编码、解码、编码范围、示例、清空、复制与全屏，说明默认收起。
- `encodeUnicode(text, scope = "all")` 默认全部编码，按 UTF-16 代码单元输出小写、四位补零的 `\uXXXX`，例如 `A你` → `\u0041\u4f60`，`😀` → `\ud83d\ude00`。
- 范围 `"preserve-ascii"` 保留 U+0020～U+007E 的可打印 ASCII，但反斜杠仍编码为 `\u005c`，保证字面的 Unicode 转义可以往返。换行、制表符等控制字符继续编码。范围只影响编码。
- `decodeUnicode(source)` 从左到右识别小写 `\u` 后的四位十六进制数字，接受数字中的大小写字母，也允许与普通文字混合。每次只还原一层：`\u005cu4f60` → 字面文本 `\u4f60`。
- 普通文字、外围引号及 `\n` 等其他转义保持原样。空输入合法，不裁剪空白、移除 BOM 或规范化组合字符。不支持 `\u{...}`、HTML 实体或 UTF-8 字节编码。
- 不完整或包含非法数字的 `\uXXXX`、编码输入或解码结果中的孤立代理项会报中文错误并保留原文；合法代理对正常还原 Emoji。转换使用纯字符串扫描，不执行输入。

### 界面状态

五个工具默认使用紧凑工具台布局：当前工具名称统一显示在约 52px 高的顶部栏，主内容区桌面内边距为 12px 16px、窄屏为 8px 12px，不限制内容最大宽度。工具说明使用原生 `<details>`，默认收起，可通过鼠标或键盘 Enter / 空格展开。空反馈不占高度，提示和错误出现时正常展开，保留读屏播报。

窗口宽度大于 820px 且高度至少 640px 时，JSON、Base64 和 Unicode 编辑区填满窗口剩余高度，编辑内容内部滚动，文字区域最小高度为 240px。展开说明或显示反馈时先缩减编辑区；超过可用空间后页面自然滚动。窄屏或矮窗口使用文档滚动，JSON、Base64 和 Unicode 文字区域至少为 280px，按钮和提示始终可达。

文本对比在桌面左右输入，输入框高度为 `clamp(200px, 32dvh, 380px)`，结果填满剩余空间并独立滚动；宽度不超过 820px 时改为上下输入，页面自然滚动。编辑卡片标题栏约 44px、字符计数栏约 24px，编辑内容内边距 12px；工具栏与编辑框间隔 8px，双栏间距 12px。不提供密度切换或拖拽分隔条。

JSON、Base64 和 Unicode 各使用一个编辑框，处理成功后直接替换框内内容，可继续编辑或反向转换；失败时保留原文。复制操作复制当前编辑框的全部内容。修改内容或选项会清除操作提示，不清空内容。时间戳工具仍独立显示输入和结果，修改输入或选项会清除旧结果。

工具切换保留当前内容，刷新后清空。用户内容只写入文本字段，绝不作为 HTML 解析。复制优先使用 Clipboard API，失败时选中内容并提示手动复制。

JSON、Base64、Unicode 编辑框标题栏提供“全屏”，在浏览器页面内展开，并保留转换工具栏、复制、字符计数和操作反馈。全屏顶部栏约 52px、内容边距 12px；当前已激活的全屏入口隐藏，统一通过顶部退出按钮或 Esc 退出。文本对比支持左右编辑框分别全屏，也可通过“工作区全屏”同时展开选项、输入和结果；工作区全屏仍保留两个单框入口，继续放大后可逐级返回。中文输入法组合输入期间的 Esc 不退出全屏。切换工具会退出所有全屏层；切换全屏不移动编辑框 DOM，编辑内容、原生撤销历史、选项及选区保留，退出后焦点返回触发按钮。

顶部标题左侧的按钮可折叠或展开导航。桌面默认展开为 196px，折叠为 72px 图标栏；窄屏只保留一行可横向滚动的工具导航，折叠时只显示图标。图标保留工具名称提示与当前项高亮。折叠状态在切换工具时保留，刷新后默认展开；导航和全屏状态均不写入本地存储。

## 构建原理

`Bun.build()` 分别在内存中生成一个 IIFE 脚本和一份 CSS，不启用代码分割或 sourcemap。构建器将它们注入 HTML 的两个唯一标记，转义可能提前结束脚本或样式的文本，并拒绝外部资源引用和额外产物。

生产构建只写 `dist/index.html`。若 `dist` 中存在其他文件，构建会明确报错，避免误删内容或交付多文件产物。开发预览复用同一流水线，关闭压缩并禁用浏览器缓存。

## 浏览器验收

1. 双击生产 HTML，在断网状态下切换五个工具，完成格式化、压缩、双向转换及文本对比。
2. JSON 输入 `9007199254740993`，确认原样保留；格式化和压缩在同一编辑框完成，非法输入保留原文并报错。
3. UTC 下转换 `-1` 纳秒，结果应为 `1969-12-31T23:59:59.999999999Z`，反向转换保留全部精度。
4. Base64 使用中文和 Emoji，测试标准与 URL 变体、连续编码再解码、空文本及非法编码时保留原文。
5. 验证复制成功提示；禁止剪贴板权限时，结果应被选中并提示手动复制。
6. 检查窄屏布局、键盘焦点、导航状态保留；确认无控制台错误和外部网络请求。
7. 文本对比中验证增删改行、行内高亮、空白与大小写选项、中文输入期间暂停计算、交换及清空；输入 HTML 类文本时确认仅显示文字。
8. 文本对比超过字符、行数或计算上限时保留原文并提示；复杂行内差异降级为整行高亮。焦点进入编辑框时无额外外框。
9. JSON、Base64、Unicode 全屏中验证转换、错误反馈、复制和编辑；通过按钮或 Esc 退出后内容、选项、选区仍保留。全屏期间 Tab 焦点仅在当前全屏层内移动，背景不滚动。
10. 文本对比验证两个单框全屏、整体全屏、整体中再放大单框以及逐级退出；输入继续自动更新结果。全屏中通过浏览器前进、后退切换工具时，确认所有全屏层正常退出。
11. 检查 320px、390px、820px / 821px、1366px、1920px 宽度及 400px 高的矮窗口：全屏退出按钮始终可达，编辑区域可滚动，无页面横向溢出；长错误信息完整展示，说明可通过 Enter / 空格展开。折叠导航后五个图标仍能正常切换工具，刷新恢复展开。
12. 默认侧栏展开、说明收起、无反馈时，JSON / Base64 / Unicode 普通模式的文字编辑区域在 1366×768 下至少 500px 高，在 1440×900 下至少 600px 高，顶部距页面顶部不超过约 160px。Chromium 实测分别为 527px / 659px，顶部均为 158px；展开说明后编辑区域优先缩小，空间不足时页面可滚动。文本对比输入和结果各自滚动，长结果不撑高整个桌面工作区。
13. 全屏中当前入口应隐藏，顶部退出按钮可用；整体对比全屏仍保留两个单框入口。输入文字后反复进出全屏，验证 Ctrl+Z 原生撤销、选区与焦点恢复，以及逐级退出行为。
14. 直接访问 `#unicode`，确认导航第 05 项高亮及标题正确；切换工具及浏览器前进、后退后保留 Unicode 内容与范围，刷新后恢复空输入和全部编码。
15. Unicode 两种范围下用中文、英文、数字、换行和 Emoji 编码再解码；保留 ASCII 时字面文本 `\u4f60` 应编码为 `\u005cu4f60` 并原样还原。解码只还原一层，范围不影响解码，外围引号及 `\n` 保留。
16. Unicode 输入不完整转义、非法十六进制或孤立代理项时，检查中文错误及原文保留；编辑内容或修改范围后提示清除。验证空输入、示例、清空、字符计数、复制成功与手动复制降级，以及全屏退出和窄屏布局。

# html-tools

### PDF 分割

- 从第 06 项「PDF 分割」或 `#pdf` 打开，选择或拖入单个 PDF，默认每页一份。也支持每 N 页（默认 10）、自定义范围和按大小（默认 10 MB）。
- 范围示例 `1-3,4-6,7`，支持中英文逗号与空白，按输入顺序生成文件，允许范围重叠；空段、倒序、非整数及越界页码会报错。
- 大小支持最多两位小数，1 MB = 1,000,000 字节。先逐页检查实际导出大小，任何单页超限都会终止整个任务，不下载部分 ZIP。再以指数扩展和二分探测实际序列化的连续页段，确保每份 PDF 不超过上限，不保证全局最少份数。
- 自动下载 `<原文件名>_split.zip`，清单显示页码及实际字节数，也可再次下载。更改设置或文件会释放旧结果；取消保留文件与设置，可重试。切换工具保留任务，刷新清空。
- `pdf-lib` 与 `fflate` 已打包到内联 Blob Worker。读取、解析和序列化都在后台进行；ZIP 按存储模式顺序写入，每块确认后才继续传输，主线程收集 Blob，不拼接完整大数组。取消直接终止 Worker。
- 面向普通 PDF 与扫描件，保留页面内容与图片清晰度；不支持加密文件、OCR 或压缩，不承诺保留文档级书签、交互表单和数字签名有效性。大文件仍受浏览器可用内存限制。ZIP32 输出限制约 4 GB、最多 65,534 份，超过时整体报错。
- 大文件验证脚本与记录见 `scripts/pdf-browser-check.mjs`、`scripts/pdf-fixtures.ts`；基准不加入默认单元测试。
